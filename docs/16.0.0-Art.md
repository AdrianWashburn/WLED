# WLED 16.0.0-Art (Dig-Octa oriented build notes)

## Source + compatibility notes
- Base source in this environment: local branch `work` (no remote/tag configured in this container).
- Because remotes/tags were unavailable locally, an exact public checkout for `16.0.0-beta` build `2604110` could not be fetched from this environment.
- To avoid core-FX patch drift, all custom art effects are implemented in `usermods/user_fx/user_fx.cpp`.

## Architecture decision
- Implemented as a **usermod (`user_fx`)** instead of editing `wled00/FX.cpp` and `wled00/FX.h`.
- This follows the WLED user_fx guidance for custom effects and keeps core firmware cleaner for maintainability/upgrades.

## Effects and controls
- Added a shared 2D Art Suite renderer and 26 effect entries (ambient + audio-reactive) inside `usermods/user_fx/user_fx.cpp`.
- Effect controls follow stock metadata constraints:
  - `Speed`, `Intensity`
  - `custom1/custom2/custom3` sliders
  - `check1/check2/check3` toggles
- Note: in user_fx, `custom3` is effectively 5-bit, consistent with user_fx documentation.

## Build for QuinLED Dig-Octa context
- Environment used: `esp32_eth` (Ethernet-capable ESP32 target in this repo).
- Built with usermods: `audioreactive user_fx`.
- Output binary:
  - `build_output/release/WLED_17.0.0-dev_ESP32_Ethernet.bin`

## How to build with user_fx enabled
1. Create `platformio_override.ini`:
   ```ini
   [env:esp32_eth]
   custom_usermods = audioreactive user_fx
   ```
2. Run:
   ```bash
   npm ci
   npm run build
   pio run -e esp32_eth
   ```
